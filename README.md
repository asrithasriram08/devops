# DevOps Laboratory

Exercises are numbered in the same order as the laboratory manual. Exercise 0
is the portfolio website; exercises 1–10 contain the required Kubernetes,
Docker, monitoring, and Jenkins deliverables.

## Exercises

| Exercise | Deliverable |
| --- | --- |
| [0 - Portfolio Website](./Exercise%200%20-%20Portfolio%20Website) | Responsive portfolio served by Nginx |
| [1 - Kubernetes Getting Started](./Exercise%201%20-%20Kubernetes%20Getting%20Started) | Nginx Pod and NodePort Service |
| [2 - Minikube Kubectl Flask](./Exercise%202%20-%20Minikube%20Kubectl%20Flask) | Flask Deployment and Service |
| [3 - Minikube Scaling Flask App with Replicasets](./Exercise%203%20-%20Minikube%20Scaling%20Flask%20App%20with%20Replicasets) | Flash-sale Flask ReplicaSet |
| [4 - Docker Networking](./Exercise%204%20-%20Docker%20Networking) | Flask, MySQL, and Redis bridge network |
| [5 - Docker Security AppArmor](./Exercise%205%20-%20Docker%20Security%20AppArmor) | AppArmor-restricted Flask container |
| [6 - Grafana Realtime Monitoring](./Exercise%206%20-%20Grafana%20Realtime%20Monitoring) | Prometheus metrics, alerts, and Grafana |
| [7 - Jenkins CI Automation](./Exercise%207%20-%20Jenkins%20CI%20Automation) | Jenkins Docker setup |
| [8 - Jenkins Hello World Job](./Exercise%208%20-%20Jenkins%20Hello%20World%20Job) | Hello World Jenkins job script |
| [9 - Jenkins Multi-Stage Pipeline](./Exercise%209%20-%20Jenkins%20Multi-Stage%20Pipeline) | Build, test, and deploy pipeline |
| [10 - Minikube Multi-Node Multi-App Minikube Deployment](./Exercise%2010%20-%20Minikube%20Multi-Node%20Multi-App%20Minikube%20Deployment) | Multi-node Minikube applications |

The `DevOps-Lab` directory is a local, untracked copy of the supplied lab
manual and is intentionally excluded from this submission.
